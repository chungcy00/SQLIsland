# 数屿SQL 新版设计 · 产品功能与边界（PRODUCT.md）

**最终版（2026-11-20 第 08 阶段）**。只记录**视觉改版期间必须保持的产品事实、交互规则与功能边界**，以及改版带来的少量新增展示行为。新版视觉规范替代旧视觉规范，但**原有功能、课程内容、数据逻辑与验证标准仍然有效**。项目根目录原有 `PRODUCT.md` 中“152 知识点/300 题”等旧口径已废弃，以本文件及 `HANDOFF.md` 为准。迁移清单（保留项、页面组件）见 `UI_MIGRATION.md` §1–§2。仅手机竖屏。

## 1. 产品事实（不变）
- 数屿SQL：安卓离线中文 SQL 学习软件，包名 `cn.sqlstudy.offline`；Java 原生容器 + 本地 WebView + 原生 JS；SQLite WASM 在 Worker 中执行；IndexedDB 保存用户记录。仅手机，最低 Android 10，锁定竖屏。
- 当前版本 0.3.8（versionCode 12）。无在线判题、无运行时 AI、无账号/云同步、无自定义题目。
- 内容规模：20 章、4 学习阶段、80 节课（kp 原编号不变）、200 练习题、200 内置闪卡（6 类，含 30 张结果预测卡）、七套 SQLite 业务库、六个业务项目、当前企业任务题 28 道。
- 课程转换状态：已转换 kp01-01/02/03、kp02-01/02、kp05-01/02（7 节）；其余 73 节为旧版内容，**不计入已转换**，视觉改版不重写、不生成替代教学结构。

## 2. 导航与模块（不变）
五项固定：首页 → 学习 → 练习 → 闪卡 → 我的。模块：学习路线与课文、练习（5 题型：独立编写/选择/填空/纠错/业务情景）、闪卡（FSRS，背面四级评级：忘记/困难/记得/熟练）、代码实验室（七库、查询历史/收藏、结果导出、ERD）、业务实战（六项目）、个人库（错题、收藏、个人闪卡、导入）、统计与设置（备份恢复、资源检查、SQL 键盘高度记忆）、版本更新。第 20 章由现有综合练习界面承载。

## 3. 必须保持的交互规则
**课文**
- 栏目顺序：核心概念 → 语法 → 执行思路 → 示例数据 → SQL 示例 → 辨析与易错点。
- SQL 示例顺序：实际需求 → 查询思路 → 分步 → 完整代码 → 运行按钮（紧邻）→ 预期结果（默认可见，实际结果单独标记）→ 解读 → 扩展示例（默认折叠）。运行按钮只执行完整查询的兼容 SQL；片段标“不能单独运行”。
- 运行时不按句号/换行/字数生成教学内容；构建与页面只消费保存的结构化结果；已转换课程默认跳过。
- 保留：关联练习、笔记、收藏、完成学习、上一节/下一节；已删除“复习相关闪卡”底部按钮不恢复。
- 合并课完成状态判定、笔记与进度迁移沿用 `curriculum-progress.js`，不改。

**练习**
- 编程题：编辑器紧接题目下方，运行结果就近展示；仅“题目 / 数据表”两个标签；数据表展示本题所需全部表，预览前 5 行，不展示隐藏夹具。
- 上/下一题固定于视窗底部、透明容器；SQL 键盘打开时仍在底部并被键盘覆盖，不抬高；键盘高度可调并记忆。
- 不恢复预测练习题型（闪卡中的预测卡保留）；无自定义题目入口。

**编辑器**：行号、语法高亮、撤销重做、全屏、底部 SQL 键盘、深浅背景切换（仅编辑器）、查询标签（实验室）。**ERD**：真实 SQLite 元数据，字段全展开，无展开/收起字段按钮；不自行推断外键。

**统计**：按现有定义与真实分母计算，“未评估”单独显示；不为视觉而改口径。

## 5. 明确不做（边界）
章节专属插画与章节地图；闪卡滑动评级；列表项左滑；横滑渐隐提示；表格首列冻结；横屏；桌面/平板/网页版；全局深色主题（仅编辑器深浅切换）；彩带/粒子/吉祥物；高频事件大图（普通答对、SQL 返回 0 行）；独立“业务指标卡”模块；新增自定义题目；改动课文、题库、闪卡、数据库、统计口径；自动发布或推送（发布须用户另行指令）。

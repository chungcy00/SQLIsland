# 数屿SQL 新版设计 · 品牌与整体风格（DESIGN.md）

**最终版（2026-11-20 第 08 阶段整合）**。本文件只定义：品牌定位、整体视觉风格、**全部色值令牌（含插画与动效相关色，唯一来源）**。字体/组件/页面/动效/适配见 `UI_SYSTEM.md`，插画见 `ILLUSTRATION.md`，功能边界见 `PRODUCT.md`，迁移与执行见 `UI_MIGRATION.md` 和 `IMPLEMENTATION_PLAN.md`，确认状态见 `DESIGN_STATUS.md`。
**与旧版的关系**：本文件夹的新版视觉规范**完全替代**项目根目录旧 `DESIGN.md`（海盐蓝 `#5B7F9C` 系令牌与页面映射）及旧插画/图标的视觉约束；根目录旧文件仅作历史参考。**功能、课程内容、数据逻辑与验证标准仍按原有要求有效**，视觉改版不改变它们（`PRODUCT.md`）。
文档间冲突按此优先级裁决：用户最新确认 > `DESIGN_STATUS.md` §1 > 本文件夹各规范文档 > 根目录旧文件。

## 1. 适用范围

- 仅 Android 手机**竖屏**（应用锁定 portrait）。不设计桌面、平板、网页、横屏版；大宽度仅做“内容最大宽 480 居中”的保护性处理，不另出设计（`UI_SYSTEM.md` §8）。
- 全局仅浅色主题。深色只用于 SQL 编辑器内部（见 §4.3），不扩展为全局深色主题。
- 功能、课程内容、教学逻辑、数据结构、统计口径、验证标准均不因视觉改版而改变。

## 2. 品牌定位

- 产品：数屿SQL，随身的数据分析面试 SQL 训练场（离线、中文）。
- 隐喻：“数据中的一座岛”——数 = 表格数据，屿 = 一块块被点亮的陆地；学习进度即岛上地块被点亮。
- 视觉概念：**环礁蓝灰**。蓝灰主色，浪沫白底，等深线与潮线作细节点缀，日光黄只做小面积高光。
- 气质关键词：清澈、克制、专业、有学习亲和力；不幼稚、不炫技、不用卡通吉祥物、不做彩带粒子庆祝。
- 取舍：品牌感靠“岛 + 等深线 + 色标语言”建立，而不是靠大面积装饰；阅读与代码区永远优先。

## 3. 整体风格

### 3.1 形状
统一圆润。圆角规格：标签全圆角；代码块、表格容器 8；输入框、按钮 12；卡片 16；底部弹出面板顶部 24。不做不对称“岛形”圆角。

### 3.2 边框与阴影
- 内容卡：白底 + 1px 浅描边 `#CFE0EA`，**无阴影**。
- 仅悬浮层使用轻阴影：底部导航、底部面板、弹窗。导航 `0 -2px 12px rgba(56,96,127,.12)`。
- 可交互控件（输入框、次按钮、选择器）边框用 `#7E98A9`（白底对比度 3.02:1）；装饰分隔线才用浅色。
- 选中状态：2px 主色描边 + 浅湖面底，并配图标或文字，不只靠颜色。
- 一个信息块最多一层框；内部用留白和细分隔线，不嵌套带边框的小卡。

### 3.3 装饰元素（仅这些，且只在指定位置）
| 元素 | 规格 | 使用位置 | 禁用位置 |
|---|---|---|---|
| 等深线纹理 | 1.25px 描边，颜色取主色，整体透明度：首页主卡 0.15；课文章节标题条 0.07（极浅）；空态/完成页可略强但 ≤0.2；无渐变 | 首页“继续学习”主卡右侧约 1/3、课文章节标题条、空态/完成页 | 正文、代码、表格、作答区、输入框背后 |
| 潮线分隔 | 单条极细自然曲线（非规则重复波浪）：描边 1px，色 `#D8E5EC`，不透明度 0.8，高 12；路径 `M0 7C22 4 41 9 66 6.5S110 3 134 6.5 182 10 210 6 262 3 291 7 338 9 360 5.5`，横向拉伸铺满 | 仅用于大区块之间（如首页内容区与学习路线之间、课文主栏目之间） | 列表内部、卡片内部 |
| 日光黄小点 | 直径 8，色 `#F0B94D` | 章节全部完成、新解锁、连续学习、答对反馈的点缀 | 作为按钮色、大面积底色 |
| 章节编号徽章 | 36×36，圆角 10，浅湖面底，Plex Sans 600 数字，主色字 | 学习路线章节行、课文标题条 | — |

不做章节地图、不做章节专属插画（见 `ILLUSTRATION.md` §3）。

全部为浅色主题令牌。**禁用紫色**（含语法高亮）。

### 4.2 语义色
| 语义 | 文字/图标 | 浅底 | 使用 |
|---|---|---|---|
| 成功 / 修正 | `#2F7A58` | `#E5F4EC` | 回答正确、“修正”块、结果保留行 |
| 警告 / 注意 | `#7A5A12` | `#FFF4D6` | 运行警告、未知类状态 |

状态必须同时有文字或图标，不能只靠颜色。

### 4.3 SQL 语法色标（教学色标）与编辑器配色
**教学色标**——只用于标签、语法结构图、执行流水线图、说明文字；**不用于代码高亮**。文字只放在白色背景上；必须配文字标签；不得单靠颜色区分。
| 概念 | 色值 |
|---|---|
| 取数 SELECT / FROM | `#38607F` |
| 筛选 WHERE / HAVING | `#2A7478` |
| 聚合 GROUP BY | `#4A7C45` |
| 连接 JOIN | `#9C5F1E` |
| 排序 / 窗口 | `#7F6A1F` |

**只读代码区（课文内）**：关键字统一主色 `#38607F` 加粗；字符串 `#7F6A1F`；数字 `#9C5F1E`；函数 `#2A7478`；注释 `#5E7281` 斜体。

**可编辑代码区（练习作答、实验室）**：专业编辑器式词法高亮。所有 SQL 关键字（含 AS/AND/OR/IN/LIKE）统一一色，不按五类色标；函数、字符串、数字、注释、字段/表名、运算符各自区分。关键字与函数不加粗。深浅背景可切换，只作用于编辑器，记忆用户偏好，不影响全局浅色主题与只读代码区。

| 词法类型 | 浅色（底 `#FFFFFF`） | 深色（底 `#162634`） |
|---|---|---|
| 关键字 | `#2B5C9E` | `#7FB2E5` |
| 函数 | `#8A5A1C` | `#E3C98A` |
| 字符串 | `#A1473A` | `#E0A07F` |
| 数字 | `#2E7A5A` | `#9FD0A5` |
| 字段/表名 | `#1B5D73` | `#9FD8E8` |
| 运算符 / 普通文本 | `#17293A` | `#E4ECF1` |
| 注释（斜体） | `#5E7281` | `#7F97A7` |

当前行浅底高亮、行号列浅灰、括号配对高亮；编辑器边框 `#7E98A9`，聚焦 2px 主色。

### 4.4 配色比例（视觉面积估算）
浪沫白 + 白卡 68%；文字墨色 15%；浅湖面 + 沙 8%；主蓝 6%；色标 2.5%；日光黄 0.5%。

### 4.5 对比度（已实测，WCAG 比值）
| 组合 | 比值 |
|---|---|
| 正文 `#17293A` / 浪沫 | 13.65 |
| 次文字 `#4F6272` / 浪沫 | 5.81 |
| 白字 / 主色 `#38607F` | 6.67 |
| 主色 / 浪沫（链接） | 6.14 |
| 青灰 `#2A7478` / 白 | 5.43 |
| 椰绿 `#4A7C45` / 白 | 4.93 |
| 赭橙 `#9C5F1E` / 白 | 5.16 |
| 橄榄金 `#7F6A1F` / 白 | 5.27 |
| 成功 / 错误 / 警告文字 在各自浅底 | 4.57 / 5.43 / 5.81 |
| 控件描边 `#7E98A9` / 白（需 ≥3） | 3.02 |
| 编辑器各词法色 | 浅色 ≥4.5（注释 `#5E7281` 约 5.0）；深色 ≥5.0 |
| 日光黄 / 白 | 1.79（只能作填充，不作文字/线条单独承载信息） |

规则：普通文本 ≥4.5:1；重要控件与边界 ≥3:1；色标文字在浅湖面底上仅 4.1–4.4，故**只放白底**。实施时用脚本对全部实际组合复核，不达标则调深浅、不改色相。

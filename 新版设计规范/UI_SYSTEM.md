# 数屿SQL 新版设计 · 界面系统（UI_SYSTEM.md）

**最终版（2026-11-20 第 08 阶段整合）**。字体、排版、间距、组件、页面、代码与表格、交互、动效、手机适配。颜色令牌见 `DESIGN.md`（唯一来源）；插画与教学图解见 `ILLUSTRATION.md`；迁移落点与执行见 `UI_MIGRATION.md`。仅手机竖屏；替代旧版视觉规范，功能与数据逻辑不变。
可运行的参考原型：`预览原型/`（home.html、lesson.html、base.css、icons.js），其 CSS/结构可直接作为组件实现参考，但不是生产代码。

## 1. 字体
- 中文：系统黑体（不打包）。栈：`"IBM Plex Sans", Roboto, "Noto Sans CJK SC", "PingFang SC", system-ui, sans-serif`。
- 英文与数字：**IBM Plex Sans**，打包字重 400/600，拉丁子集（约 200KB，OFL 许可）。
- 代码：**JetBrains Mono**，字重 400/600，拉丁 + 数字 + SQL 常用符号子集（约 200KB，OFL）。中文注释回退系统字体。
- 全局开启等宽数字（`font-variant-numeric: tabular-nums`），统计、进度、表格数字对齐。
- 字体文件随 APK 离线打包；不得依赖网络字体（预览原型使用 Google Fonts 仅为预览）。

## 2. 字阶与信息层级
只用 6 级字号、2 个字重（400 / 600；不用 300）。
| 层级 | 用途 | 字号/行距 | 字重 | 色 |
|---|---|---|---|---|
| 页面标题 | 一级页大标题、课程标题 | 22 / 1.3 | 600 | `--ink` |
| 区块标题 | “核心概念”“SQL 示例”等栏目 | 17 / 1.4 | 600 | `--ink` |
| 小标题 | 概念内小标题、卡片标题 | 15 / 1.45 | 600 | `--ink` |
| 正文 | 课文、题干、解析 | 15 / 1.65（紧凑） | 400 | `--ink` |
| 辅助 | 说明、标签、元信息 | 13 / 1.5 | 400 | `--ink2` |
| 微标注 | 单位、角标 | 11.5 / 1.4 | 400 | `--ink2` |
- 代码默认 14 / 1.55（沿用现有可调范围 12–20）；表格单元 13 / 1.4。
- 段落间距 0.75 倍字高，列表项 0.4 倍。强调用 600 字重 + 主色，不用下划线、大面积底色。
- 全部使用相对单位，跟随系统字体缩放；设置新增“正文字号：标准 15 / 大 17”两档（与系统缩放叠加）。系统字体 1.3 倍下不得换行崩坏、遮挡按钮或整页横向溢出。

## 3. 间距与布局
- 间距刻度：4 / 8 / 12 / 16 / 24 / 32。页边距 16（视口 <360 时 12）；卡片内边距 16，紧凑卡 12。
- 单列布局，顶部栏高 56，底部导航高 64 + 安全区，内容底部留 80 + 安全区。区块间 24（大区块 32），标题上 24 下 8，标题与内容 12。
- 密度分页面：
  - 标准：首页、课文详情、练习作答、闪卡复习、设置。
  - 紧凑（列表项约 48–64）：学习路线列表、题库列表、错题与收藏列表、统计明细、数据表与 ERD 的表列表。
- 任何可点击元素 ≥44×44，主操作 48 高，相邻可点元素间距 ≥8；小图标扩展点击区到 44。

## 4. 组件
### 4.1 底部导航
五项固定：首页 → 学习 → 练习 → 闪卡 → 我的。图标 + 文字常显；选中项：`--lake` 圆角胶囊底（56×30）+ 图标实心主色 + 文字主色。白底，顶部 1px `--line`，轻阴影。上/下一题固定底部、透明容器、SQL 键盘覆盖而不抬高的既有规则不变。

### 4.2 顶部栏
高 56，背景同页面，滚动后出现 1px `--line` 描边。一级页：左对齐大标题 22。二级页：居中标题 17/600（单行省略）+ 返回（44×44）+ 右侧至多两个图标按钮（收藏、更多，各 44×44）。系统返回手势与返回键保持有效。

### 4.3 按钮
| 类型 | 样式 | 用途 |
|---|---|---|
| 主 | 主色填充、白字、圆角 12、高 48 | 运行、提交、开始/继续学习、完成学习 |
| 次 | 白底、1px `--ctl` 描边、主色字 | 提示、查看答案、上一题/步 |
| 文字 | 无底无框、主色字、高 44 | 取消、跳过、查看更多 |
| 危险 | `--err-bg` 底、错误红字 | 删除、清空，仅出现在确认弹窗内 |
| 图标 | 44×44 无底，图标 24 | 工具栏 |
状态：按下深一档（主按钮 `--primary-press`，次按钮浅湖面底）；禁用 40% 透明且保留文字；加载在按钮内显示小圆环并保持原宽。日光黄不作按钮色。

### 4.4 标签、徽章
- 标签：全圆角、高 24、横向内边距 10、12/600。状态标签 = 浅底 + 深字 + 图标（如“✓ 已完成”）。色标标签 = 左侧小色块 + 文字。题型标签统一用主色描边 + 文字，不用多色区分。
- 章节编号徽章：见 `DESIGN.md` §3.3。

### 4.4a 卡片（三形态）
1. 内容卡：标题 + 正文（课文、解析）。
2. 列表卡：左图标/编号徽章，中标题 + 副标题，右状态或箭头，整行可点，高 56–64。
3. 主卡：仅首页“继续学习”，浅湖面底 + 等深线 + 数据岛，一个主按钮。
知识头部与概念区不加外围框（沿用既有规则）。

### 4.5 进度与状态
- 状态图标三态：未学（空心圈，描边 `--ctl`）／学习中（半填主色）／已完成（实心主色 + 白勾）。章节全部完成时，章节名旁加日光黄小点。
- 章节进度：6px 圆头横条（浅湖面底、主色填充），旁写“已学/总数”（如 3/5）。

### 4.6 底部弹出面板
顶部圆角 24；白底；顶部居中拖拽条 36×4（`--line`）；背后遮罩墨色 40%；轻阴影。高度随内容，最高 85% 屏高，超出内部滚动，底部加安全区。标题行高 56（17/600 + 关闭 44×44）；列表项高 56，选中 = 右侧主色对勾 + 文字。滑入 220ms / 退出 180ms。可通过拖拽条、下滑、点遮罩、返回键、关闭按钮关闭。

### 4.7 弹窗（仅不可逆确认：覆盖、删除、清空、恢复）
居中，宽 = 屏宽 − 48（最大 320），圆角 16，白底，轻阴影。标题 17/600 + 一句说明（必须说清后果与能否撤销）+ 两按钮并排（高 48）：左“取消”（次）、右确认（危险操作用危险按钮）。点遮罩不关闭；返回键 = 取消。其余选择类交互一律用底部面板。

### 4.8 展开收起
标题行整行可点（高 48–56），右侧箭头展开时旋转 180°，折叠态显示一句摘要。200ms 高度动画，展开后页面位置不跳，尊重系统“减少动画”。展开内容与标题间距 8。用于：扩展示例、提示、查看答案、解析、辨析分组、分步执行。

### 4.9 图标
线性 + 局部填色：1.75–2px（24 画板）圆头圆角；功能/导航 24，列表装饰 20；局部填充用浅湖面；日光黄每个图标至多一处且面积极小；选中态 = 线性 + 主色实心填充；通用图标（返回、关闭、复制）与功能图标同线宽同圆角；新图标以真矢量 SVG 绘制。12 个功能图标 + 5 个导航图标纳入重绘（图案待样张确认，见 `DESIGN_STATUS.md`）。

## 5. 代码与表格
### 5.1 课文代码展示区（只读）
默认自动换行，右上角开关可切为横向滚动，偏好记忆（try/catch 保护 localStorage）。头部浅湖面：左“MySQL · 兼容”标签，右换行开关与复制按钮（均 44×44）。圆角 8，白底，1px `--line`。配色见 `DESIGN.md` §4.3。顺序与既有规则不变：完整代码 → 运行按钮紧邻 → 预期结果（默认可见）→ 实际结果（单独标记）→ 解读 → 默认折叠的扩展。

### 5.2 可编辑代码区
保留全部现有功能：行号、撤销重做、全屏、底部 SQL 键盘（高度可调并记忆）、深浅背景切换。样式：白底（深色 `#162634`）、边框 `--ctl`、圆角 12、聚焦 2px 主色；行号列浅湖面底；键盘区浅湖面底、按键白底圆角 8 高 44、分组间距 8。实现上复用现有 `--editor-*` 变量（`src/style.css` 中 `.sql-editor` 及 `.dark` 段）。

### 5.3 查询结果表格
横向滚动，**不冻结首列**（宽表可读性需用真实宽表验证，见 `DESIGN_STATUS.md`）。表头浅湖面底 13/600；数字右对齐、等宽数字；文本左对齐；NULL 显示为浅色斜体“NULL”，空字符串显示 `''`；窄表（≤3 列）不撑满宽度。预期结果浅湖面底、实际结果白底，分别带标签；预览前 5 行（规则不变）。代码与宽表独立横滑，不引起整页横向滚动；不加横滑渐隐提示。

## 6. 页面规范
### 6.1 首页（标准密度）
顺序：页头（一级页大标题“数屿 SQL”+副标题+搜索）→ 继续学习主卡 → 闪卡/今日练习两张次卡 → 业务实战/代码实验室入口 → 潮线 → 学习路线（紧凑）。
主卡：浅湖面底 + 右侧等深线 + 数据岛（1:1，约 150×150，可略出卡片右缘），左侧标签“继续学习”（白底标签）、课程标题 22、章节/用时辅助行、进度条、主按钮。小屏 <360：岛缩至 112、上移，文本区最大宽 70%，避免遮挡进度数字。数据岛点亮规则见 `ILLUSTRATION.md` §1。

### 6.2 学习路线（紧凑）
阶段标题 15/600，右侧“共 N 章 · 已完成 M”。章节行（高约 60–64）：编号徽章 + 章名 + 横条进度 + “已学/总数”；展开后知识点行（高 52，缩进 16）：状态图标 + 标题 + 题数小标签。保留阶段筛选、自由学习搜索、章节展开。

### 6.3 课文详情页（栏目顺序固定不变）
顶部栏（二级页，居中短标题）→ 章节标题条（见下）→ 吸附的章节内导航 → 主栏目**全部展开**：核心概念 → 语法 → 执行思路 → 示例数据 → SQL 示例 → 辨析与易错点 → 页底“上一节 / 完成学习 / 下一节”（及既有笔记、收藏）。
- **章节标题条**：浅湖面底、极浅等深线（透明度 0.07）、编号徽章 + “第 N 章 · 章名”、课程标题 22、学习目标（沿用现有“能够运用本节知识完成：”前缀规则）、类型标签。**不显示知识点内部编号**（如 kp05-01）；仅在调试模式下显示（调试入口待定，见 `DESIGN_STATUS.md`）。
- **章节内导航**：“概念 / 语法 / 示例 / 易错”四个胶囊（高 40，吸附于顶部栏下），点击平滑滚动到对应栏目，滚动时自动高亮当前栏目；“示例”涵盖执行思路、示例数据、SQL 示例。
- **核心概念**：无外框；小标题 + 短段落 + 项目符号；对比表/逻辑表用独立横滑表格；概念图见 `ILLUSTRATION.md` §4。
- **语法**：语法结构图（见 `ILLUSTRATION.md` §5）+ 用途说明 + 参数项目符号（紧凑右缩）。
- **执行思路**：紧凑编号列表（主色圆点数字），短句，前置于示例数据之前，不放代码与表。
- **示例数据**：小标题与表名标签分开但紧凑；字段/单位/粒度说明紧贴示例表；不插在完整代码与运行按钮之间。
- **SQL 示例**固定顺序：实际需求 → 查询思路 → 分步执行 → 完整代码（单列标题）→ 运行按钮（紧邻）→ 预期结果 → 解读 → 扩展示例（默认折叠）。
  - **分步执行**：一张白卡，所有步骤各占一行：序号圆标 + 步骤名 + SQL 片段摘要 + **行数徽章常显**（如“4 → 1 行”）；仅当前步展开（表格、片段“不能单独运行”标签、说明），其余折叠为一行摘要；点击任一行跳转；底部“上一步 / 下一步”按钮；无小圆点。默认展开哪一步见 `DESIGN_STATUS.md`。
  - 片段标明“片段 · 不能单独运行”，不提供运行入口；仅完整查询有运行按钮（沿用既有规则）。
- **辨析与易错点**：**白色卡片**（1px 描边），内部按类型分块，靠小标签和局部浅色底区分：辨析（浅湖面标签）、易错（`--err-bg` 底 + “✕ 易错”标签 + 代码）、原因（`--lake` 底）、修正（`--ok-bg` 底 + “✓ 修正”标签 + 代码）、注意（白底）。各块独立，不得互相复制内容；不使用大面积黄色底。
- 保留：关联练习、笔记、收藏、完成学习、上一节/下一节。

### 6.4 闪卡
正面：白卡（圆角 16）居中大字，点击翻面，正面不放图。背面：答案 + 四级评级按钮横排（高 48）：忘记（错误浅底）/困难（警告浅底）/记得（提示浅底）/熟练（成功浅底），文字常显。面试知识图仅在背面解析内（见 `ILLUSTRATION.md` §8）。

### 6.5 练习与答题反馈
- 两标签：题目 / 数据表。题干在上，编辑器紧接下方，运行结果就近展示；数据表展示本题所需全部表，预览前 5 行，不公开隐藏夹具。上/下一题固定底部、透明容器、键盘覆盖不抬高。
- 长题干：默认显示 6 行 + “展开全文”；作答时可折叠为一行摘要，保证编辑器与结果在可视范围。题目大标题只保留主题。
- **答题状态条**（反馈区顶部，编辑器与结果之后就近展示）：正确 = 成功浅底 + 勾 + “回答正确”；结果不一致 = 错误浅底 + 叉 + “结果与预期不一致” + 一句差异摘要（如“少 2 行”）；运行/语法错误 = 警告浅底 + 感叹号 + 数据库原始错误（等宽）。出现 150ms 淡入；无弹跳、无庆祝动画；正确时仅右侧一个日光黄小点。
- **结果对照**：“预期 / 实际 / 差异”三标签切换，失败后默认停在“差异”。差异标签内：不一致单元格用错误浅底 + 加粗，缺失行/多余行在行首加文字标记“缺”“多”。
- 提示、查看答案、解析为默认折叠的可展开区块。

### 6.6 其余页面
实验室、实战、个人库、统计与设置、ERD：沿用现有结构与功能，仅按令牌、组件、密度规则换肤；不新增栏目。第 20 章由现有综合练习界面承载。

## 7. 手势、动效、单手操作
- 单手分区：下部放导航、运行/提交、上下题、评级、键盘；中部为阅读/编辑/结果；上部放返回、标题、低频操作。
- 新增手势仅一个：**题目左右滑动切换上/下一题**。规则：仅在题干文字区与空白处起滑生效；代码块、编辑器、结果表格、SQL 键盘内起滑不触发；横向位移 ≥80px 且 ≥ 纵向位移 2 倍；左边缘 20px 内不触发（让给系统返回）；首/末题仅轻微回弹；键盘打开时不触发；上/下一题按钮保留。
- 不新增：闪卡滑动评级、列表项左滑、横滑渐隐提示。
- **动效总表（唯一定义）**：

| 动效 | 时长 | 备注 |
|---|---|---|
| 按下反馈 | 100ms | 浅主色底 |
| 答题状态条淡入 | 150ms | 无弹跳、无庆祝 |
| 展开收起 | 200ms | 高度动画，页面位置不跳 |
| 底部面板 进 / 出 | 220ms / 180ms | 滑入/滑出 |
| 里程碑 | 约 600ms，**只播放一次** | 12 块地块每块间隔 28ms 依次亮起（约 340ms）→ 旗子上移 34px 并淡入（约 260ms）→ 保持最终状态；规则见 `ILLUSTRATION.md` §13、`UI_MIGRATION.md` §5.2 |
  - 缓动：进入 ease-out、退出 ease-in（**实施默认值，预览未指定，待确认**，`DESIGN_STATUS.md` #24）。
  - 不做：自动播放、循环、弹跳、粒子、首页岛动画、鼓励图动画（13 内光点为静态）。
  - **系统“减少动画”**（`prefers-reduced-motion: reduce`）：以上全部取消过渡，直接显示最终状态；里程碑直接呈现最终态。

## 8. 手机适配与安全区
- 档位：紧凑 320–359（边距 12，字号不缩小，导航文字 11.5 不省略，按钮仍 48）；标准 360–429（基准，边距 16）；大屏手机 ≥430（边距 16，字号不放大）。流式布局，最小支持 320，不写死像素宽。
- 大宽度（折叠屏展开等，应用仍竖屏锁定）：**仅保护性处理**——内容最大宽度 480 居中，不另做平板/桌面设计。现有 975 宽度的课文版式检查脚本仅作回归，不代表存在桌面设计。
- 顶部：内容延伸到状态栏之下（Android 15/16 强制全屏），顶部栏内容下移状态栏高度，状态栏图标深色。底部：导航与固定按钮加手势条高度，背景延伸到底边；内容底部留 80 + 安全区。保持 `adjustResize`，光标所在行始终可见。
- 继续**锁定竖屏**。现有基础：`AndroidManifest.xml` 已设 portrait；`index.html` 已有 `viewport-fit=cover`；样式已使用 `env(safe-area-inset-bottom)`。

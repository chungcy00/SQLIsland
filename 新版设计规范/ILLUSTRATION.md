## 0. 共用规则

**两层体系**
- 情感层：**最终形态 = 用户提供的 14 张位图插画（§12，业务六图、空态、就绪、鼓励、加载失败、品牌）+ 两个矢量（首页进度岛 §1、里程碑 `milestone.svg` §13）**。数量少，传达氛围，不承担知识。（早期“全部手工矢量”的表述作废。）
- 教学层（§4–§8 的概念图、语法图、函数图、执行与关系图、指标公式卡与面试图）：**组件化 SVG，由课程数据驱动**，不画成固定图片。图中所有数据必须来自课程示例数据和已验证结果，**禁止手写数值**；改课程数据即改图。

**视觉规则**
- 线 1.75px 圆头圆角；全部扁平，无渐变、无阴影、无 3D；每图至多 4 色：墨 `#17293A`、主色 `#38607F`、浅湖面 `#E2ECF2` + 一个点缀（日光黄 `#F0B94D` 或青灰 `#2A7478`）。教学色标仅用于表示“子句”并必须配文字。禁紫色。
- 文字一律为真实文本（不烘焙进图），字号 ≥11.5，字体沿用 IBM Plex Sans/系统黑体，代码用 JetBrains Mono。
- 每张图配替代文字；颜色之外必有形状或文字区分；关键信息不放在插画里；插画不遮挡学习内容（不进入正文流，除教学图解本身）。
- 格式（仅教学层与首页进度岛）：内联 SVG，颜色用 CSS 变量，单张 <8KB；8px 网格；比例仅用 1:1、4:3、3:2、16:9。情感层位图与里程碑矢量按 §12–§13 的既定格式，不受 <8KB 限制。
- 不用的东西：章节专属插画、章节地图、彩带粒子、吉祥物、拟物比喻（机器、管道等）。

**教学图解组件库**（一次实现，所有图解复用）：迷你表（表头浅湖面、网格 `--line` 1px）、高亮单元格（日光黄浅底）、引线标注、变换箭头、左右对比容器、括号、行条、行数徽章、色标竖条、占位符块、函数名块、步骤行。

**数据来源与校验**：图解数据取自课程结构化数据与已验证的执行结果；片段步骤不画成真实结果；只有带完整夹具/中间结果的步骤才画“数据变化”。仅处理已转换的课程；未转换课程不生成图解。已转换 7 节原文不得被修改，图解以**可选新增字段/块**挂接。

## 4. 核心概念图（教学层）
- 原则：只有文字难以说清的概念才配图，**不强制每节都有**；每节最多一张概念图；紧跟对应概念段落，不放在示例数据与 SQL 区之间。
- 适用类型：结构类（表/行/列/主键）、对比类（WHERE vs HAVING、INNER vs LEFT）、数据变化类（去重、聚合、排序）、逻辑规则类（NULL 三值逻辑）。
- 画法：数据精确的迷你表线框；每图一个知识点；迷你表 ≤5 行 × 4 列；标注 ≤3 条、每条 ≤8 个汉字；重点单元格日光黄浅底；错误/被排除行 = 错误浅底 + 删除线 + 文字；一图最多一个重点色；对比类左右并排（窄屏上下堆叠）。
- 尺寸：宽随版心（约 358），高自适应 ≤180；宽表独立横滑。外层为白卡（1px 描边）。
- 交互：**点按标注高亮对应部分**（其余变淡，再点取消）；标注为 ≥44 高的按钮，选中 2px 主色描边 + 浅湖面底；无动画依赖。
- 范例：`预览原型/lesson.html` 的“三值逻辑”图（kp05-01）。

## 5. 语法结构图（教学层）
- 只表达**书写结构**；执行顺序归 §7，不在此重复。位置：“语法”栏目内、参数项目符号之上。
- 画法：**色标块堆叠**。每个子句一行（白底、圆角 12、1px 描边）：左侧 4px 色标竖条 + 子句名（色标色，如“取数/筛选/排序”），右侧等宽模板片段，占位符为浅湖面小块（圆角 6）；可选子句用虚线框 + “可选”标签；关键字在此用主色加粗。≤6 行、每行 ≤3 个占位符、行尾说明 ≤12 个汉字。
- 尺寸：全宽约 358，行高 ≥44，行间距 8。
- 交互：**点占位符，行内展开一句说明与取值示例**，再点收起；沿用展开收起规则。说明与示例的文字须来自课程数据（现有 `syntax` / `parameters` 字段或新增可选字段），不得自拟。
- 范例：原型 lesson.html “语法”栏目。

## 6. 函数用法图（教学层）
- 用“**标量 / 聚合 / 窗口**”三种形态突出行数变化：
  - 标量：N 行 → N 行，逐行一一连线（1px `--line`）；
  - 聚合：N 行 → 1 行（或每组 1 行），行条向中间收拢；
  - 窗口：N 行 → N 行，右侧多出一列并高亮。
- 组成：①函数调用解剖（如 `ROUND(price, 2)`，括号 + 引线标出函数名与各参数，标签 ≤8 字）；②输入迷你表 → 函数名块（浅湖面底 + 主色线框）→ 输出迷你表，输入/输出各 ≤4 行 × 2 列，输出变化值日光黄浅底，NULL 浅色斜体；③行数标记小字（“3 行 → 3 行”）。
- 布局：宽度 ≥360 左→右；<360 竖排（输入在上、函数名居中、输出在下）。宽 358，高 ≤200。位置：行数变化图放在概念栏目；函数调用解剖放在语法栏目；不插入示例数据与代码之间。
- 交互：以**点参数高亮**为基础（高亮输入列与输出变化）。对涉及空值、边界值、特殊取值且具有实际教学价值的函数，额外支持“典型 / 边界 / NULL”**样例切换**；仅在课程已有对应样例数据并经过结果验证时才提供，不强制所有函数有三类样例，不修改原课文。

## 7. 查询执行与数据关系图（教学层）
放在“分步执行”与示例数据区域；**不插入完整代码与运行按钮之间**。
1. **执行流水线图**：画该查询用到的逻辑执行顺序（FROM → JOIN → WHERE → GROUP BY → HAVING → SELECT → ORDER BY → LIMIT，只画用到的）；每步一行：色标竖条 + 文字标签 + 一句“这步做了什么” + 行数徽章（“12 → 7 行”）。
2. **数据变化图（逐步）**：每步一张迷你表（≤5 行 × 4 列；更多行显示前几行 +“…共 N 行”）；被过滤行灰字 + 删除线 + 文字“被过滤”；新增列/变化值日光黄浅底；被合并行用括号收拢；保留行 `--ok-bg` 浅底。只有课程提供完整中间结果的步骤才画。
3. **表关系图（连接为主）**：左右两张迷你表 + 行匹配连线；不匹配行用虚线指向 NULL；对 INNER/LEFT/RIGHT/FULL 与一对多重复行分别画出保留、变 NULL、重复。**韦恩图仅作补充小图示**，不作主图。
- 尺寸：宽 358；单步图高约 120–160；一次最多 5 步；标注 ≤12 个汉字。
- 交互：**步进查看**——当前步展开，其余步折叠为一行摘要（序号 + 步骤名 + 片段 + 行数徽章，行数徽章常显）；点任一行跳转；“上一步/下一步”按钮；不做自动播放动画。布局见 `UI_SYSTEM.md` §6.3。
- 范例：原型 lesson.html “分步执行”（kp05-01 的 `WHERE value <> 10`）。

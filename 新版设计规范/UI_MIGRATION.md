## 5. 首页进度岛与里程碑动画接入规则

### 5.1 首页进度岛（B3）

- 点亮顺序：后排自左至右、逐行向前（与里程碑 tile-1…12 同序）。
- 无动画（首页只反映当前进度）；岛为装饰：`aria-hidden="true"`，进度以主卡文字（“已学 N/总数”）呈现。

### 5.2 里程碑动画（B10）
- 素材：`milestone/milestone.svg`（3:2，约 51KB，无脚本/外链/字体）。接入方式：构建期读取并内联为字符串，**仅在里程碑画面渲染时注入，且一页最多一个实例**（SVG 内 id 唯一）。
- **构建前提**：现有 `scripts/build.mjs` 复制 `resources/ASSETS` 时过滤掉所有 `.svg` 和 `.md`（核对于 `cp(assetSource, "dist/assets", …filter)`），故 `milestone.svg` 目前**不会进入包**；同时会把整个 `v2/illustrations/final/source/`（约 28MB 原图与分层）与 `v2/illustrations/business/` 试验图一并打包。B10 必须先调整构建（显式白名单：只含 `v2/illustrations/final/*.png` 与 `milestone.svg`；排除 `final/source`、`business`、`tools`、`test.html`、所有 `.md`），并核对被过滤的既有 `.svg` 是否被其他资源依赖。这是对 `IMPLEMENTATION_PLAN.md` 旧表述“无需改 `build.mjs`”的更正。
- 状态规范：未亮 `.tile` fill `#F3F8FA`/stroke `#A9C2D2`（3px）；亮 `.tile.on` fill/stroke `#38607F`；旗面 `#F0B94D`、旗杆 `#17293A`；`#flag` 外层做位移/透明度。
- 时序：进入画面 → 12 块按编号每块间隔 28ms 点亮（约 340ms）→ 旗子上移 34px 并淡入（约 260ms）→ 总约 600ms；**只播放一次**并保持最终状态；岛体/植物/岩石/等高线/地块位置不动。
- **默认最终态、失败安全**：服务端模板输出全部 `on` + 旗子可见；仅当系统允许动画时，脚本在插入后同步重置为未亮再播放，避免脚本失败得到空岛。系统“减少动画”（`prefers-reduced-motion: reduce`，用 `matchMedia` 判断）→ 不重置、不播放。
- 触发：每次进入该完成画面播放一次；同一画面内因状态刷新而重渲染不重播；播放状态不持久化、不进备份、不计统计。
- 无障碍：图装饰性（`aria-hidden`/`alt=""`）；达成内容用页面文字（如“今日闪卡已完成 N 张”）；至多一个“下一步”按钮。
- “重播”按钮仅限预览页，正式软件不出现。
- 位图 `12_milestone.png` 仅作 SVG 无法加载时的静态备用。

空值判断与三值逻辑

能够区分未知值、零与空字符串，并正确筛选缺失、已知以及明确不等于指定值的记录。

语法课kp05-01 · debug

核心概念

缺失与已知值

NULL 表示未知或缺失，不是数字 0，也不是长度为零的文本。

  • 普通比较例如 value = 10 或 value <> 10，遇到 NULL 通常得到未知，而不是假。
  • SQL 的条件判断采用真、假、未知三种逻辑值；WHERE 只保留真，因此未知记录会被排除。
  • 判断缺失要用 IS NULL，判断已知要用 IS NOT NULL。

未知条件如何通过筛选

NOT 不会让未知变成真。

  • 业务上缺失不一定是错误：订单客户外键为空可能意味着允许访客购买，也可能是数据遗漏，须结合业务规则判定。
  • 计数非空字段会跳过缺失，与总记录数不同。

本节核心语法。IS NULL 用于查缺失；主查询刻意使用 <> 10，展示普通比较会排除未知值。两种任务的代码不能互换。

  • IS NULL：检查字段是否为空值
  • IS NOT NULL：检查字段是否已有值
  • <>：不等于，普通比较遇空值为未知

执行思路

  1. 比较数值与 10
  2. 排除未知及等于 10 的记录
  3. 单独检查缺失记录

辨析与易错点

    

      
辨析
NULL、0 与空字符串不同；NOT(value=10) 不会自动包含 NULL。

      
✕ 易错
用等号判断缺失，或认为不等于 10 的普通比较会自动包含缺失行。
WHERE value = NULL

      
原因
普通比较遇到 NULL 产生未知，= NULL 和 <> 10 都不能用来选择缺失行。NOT 对未知取反也仍是未知。

      
✓ 修正
用空值判断检测缺失；若还需要已知不等于 10 的记录，将两个条件用 OR 连接。
WHERE value <> 10 OR value IS NULL

      
注意
是否将匿名订单或缺失值列入指标，需要明确数据口径。

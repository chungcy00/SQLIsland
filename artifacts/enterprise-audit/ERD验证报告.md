# ERD 关系图实施与验证报告

2026-11-18 · 数屿SQL 0.3.0 · 企业资源4.2.0

## 入口与交互

代码实验室保留“数据表｜代码｜结果”，数据表内增加“数据表列表｜ERD关系图”，初始显示列表。按最新要求始终展示全部字段，移除展开、收起按钮。

支持单指拖动、双指缩放、全屏、适合屏幕、恢复布局、搜索定位、关联高亮、一层及两层聚焦、字段说明和表预览。超过24个对象的库默认聚焦一层关联，可切回全部表。表预览一次展开一张，切换时原位收起前一张。

沿用现有 JavaScript 与 WebWorker 架构，独立组件位于 src/erd.js，布局使用随应用构建的 Dagre 1.0.4。字典和依赖均在本地。字体、配色、主导航与插画沿用现有设计。

复合外键按约束编号及列序配对，连线落在实际字段行。可空外键标为0..1；引用列组合完整唯一时子表端最多1，否则为N。条件唯一索引显示UK*，不用于无条件一对一推断。测试覆盖复合键、可空普通TEXT主键、INTEGER主键、WITHOUT ROWID、条件唯一、表达式索引、标识符大小写及特殊表名。 [SQLite 建表语义](https://www.sqlite.org/lang_createtable.html)

## 实际测试

- 七库表、字段、主键顺序、外键组、唯一索引核对通过，数据库文件SHA-256与ERD实施前一致。
- 浏览器加载全部七库，所有卡片无重叠，外键端点与实际字段行坐标一致。
- 实际触摸事件验证单指拖动、双指缩放，搜索、高亮、范围切换、重置、全屏和预览通过。
- 个人SQLite库的复合外键与无关系字段正常；名为__proto__的表正常布局。代码编辑器新增个人表后，列表与ERD同步刷新。
- 覆盖320、360、390、430、975像素宽度，无页面横向溢出。禁用Object.hasOwn和structuredClone后正常入口仍可运行，浏览器没有外部资源请求。
- Android16模拟器关闭Wi-Fi与移动数据后，七库全部字段、外键、视图依赖核对通过，未出现字典缺失。
- 12个自动测试通过，原有775组参考执行无失败；企业50题另有408次WASM参考及等价解执行通过。
- 33条浏览器路由以及学习、练习、闪卡、导入和备份流程通过。

## 修复的集成问题

构建原先只复制SQLite，遗漏七份schema.json，导致业务库关系图加载报错。现在会复制字典并记录路径和哈希，缺文件会使构建失败。运行时字典异常会明确提示，并继续展示真实数据库结构。

数据集切换增加过期请求保护，个人库建表后刷新结构缓存。表预览支持单张展开和过期查询保护。练习大标题保留简短标题，完整题目保留于正文；SQL键盘支持高度记忆和完整的全屏图标。

## 验证边界

实体Android10/16尚未测试。当前七库视图均成功解析，其他个人库遇到暂不支持的视图语法时会显示结构提示。视图表达式未声明类型时显示“—”，个人字段缺少字典时明确显示未提供中文说明。复杂连线仍可能交叉。

模拟器的IndexedDB文件曾损坏并被WebView重建，历史记录保留验证未通过，损坏发生时间未确认。日志位于emulator-storage-corruption.txt。浏览器从真实0.2.1构建升级至0.3.0，完成状态、笔记、收藏、草稿等九类状态保留检查通过。

原生MySQL8.4尚未运行。BP36和BP39在完整公开主库中无核对差异，预期为空集，独立隐藏场景包含缺失入库、结算差额，硬编码空集会被拒绝。其他业务口径及限制见[审核报告](审核报告.md)。

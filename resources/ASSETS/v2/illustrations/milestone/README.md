# 里程碑岛（可逐块点亮的矢量版）

状态：**已确认采用（2026-11-20）**；已接入样稿页，未接入正式软件，未改其他插画资源。
- `milestone.svg`（约 51KB，viewBox 1536×1024 即 3:2，透明背景，无脚本、无外链、无字体依赖）
- `test.html`：把 SVG 内联的动画预览（重新播放按钮、支持系统“减少动画”）

## 重建方式
参考图 A（空岛）为几何基准，用 vtracer 描摹岛面、侧壁、植物、岩石；等高线与水波按骨架重建为平滑描边（保留原图淡色与粗细）。地块形状取自参考图 C 的 12 块平均形状，栅格（间距与走向）取自 C，按岛面中心平移缩放到 A 上；旗子由参考图 D 描摹并改为规范色。参考图 B 只作未点亮样式参考（它只有 11 块，不沿用）。脚本：`../tools/build_milestone.py`（依赖 vtracer、numpy、pillow、scipy、scikit-image，需独立 venv）。

## 元素编号
| 元素 | 说明 |
|---|---|
| `#island` | 岛体总分组：岛面、侧壁、植物、岩石、水波 |
| `#contours` | `#island` 内的等高线与水波描边（8 条） |
| `#tiles` | 12 块地块分组 |
| `#tile-1` … `#tile-12` | 地块，类名均为 `tile`；点亮顺序即编号顺序 |
| `#flag` | 旗子分组（旗面 #F0B94D，旗杆 #17293A）；内部再套一层 transform，外层 `#flag` 可被 CSS 位移/透明度动画 |

## 地块排布与点亮顺序
4 列 × 3 行，共 12 块。行由后向前（tile-1~4 为后排，5~8 中排，9~12 前排）；行内从左到右。
- 未点亮：fill `#F3F8FA`，stroke `#A9C2D2`，stroke-width 3。
- 已点亮：fill 与 stroke 均 `#38607F`（预览页用 `.tile.on` 覆盖）。

## 动画（test.html）
初始：12 块未点亮、旗子隐藏。每块间隔 28ms 点亮（约 340ms 完成），随后旗子上移 34px 升起并淡入（约 260ms），整体约 600ms，播放一次后保持最终状态；岛体、植物、岩石、等高线、地块位置不变。系统开启“减少动画”时直接显示最终状态。

## 已验证
浏览器内 320 / 360 / 390 / 430 宽度无横向溢出；12 块、编号 tile-1→tile-12、点亮顺序（后排左→右逐行向前）、旗子在 12 块之后升起；“减少动画”分支（用替换 matchMedia 的方式模拟）直接显示最终状态。
未验证：真机/WebView、真实系统“减少动画”开关、屏幕阅读器。

## 与参考图的已知差异
- 水波与等高线是平滑描边，没有原图水彩的浓淡变化；侧壁是平色，没有原图渐变（规范不要渐变）。
- 岛面是平色，没有原图的纸纹颗粒。
- 旗子大小按 0.72 缩放，固定在最后一排地块后方。

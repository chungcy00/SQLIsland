# 统一导入说明

本包包含第二至第十一批73节，第一批7节只参加核验不再导入。正式编号80个、独立合并来源53个、映射55条；本包278项复验记录，另有第一批16项，共294项均在本地重新运行成功。合并覆盖是编号及已有教学映射的检查，并非逐篇复核精简前全文。

## 操作

1. 在实际本地仓库确认课程目录与课程5.0.0基准兼容，尤其确认原主查询、夹具和本地未提交变更；本工具不自动判断所有语义版本冲突。
2. `python 统一导入.py /本地项目路径`：默认只预检80个正式编号及73个补丁目标，不修改文件。
3. 确认版本及差异后运行 `python 统一导入.py /本地项目路径 --apply --backup /独立新备份目录`。工具只替换补丁明确列出的字段；教学对象逐字段更新，未列出字段保留。原始课程文件先备份。已有本地同字段的修改须人工确认，不要盲目覆盖。
4. `python 统一复验.py`：独立运行25批复验文件。各批夹具相互隔离，不直接合并进项目数据库。写入和事务例子只在临时数据库执行。
5. 在真实应用中验证渲染、示例依赖及执行按钮。保留原主查询及原结果、题卡关联、进度和布局；不新增模块。原始分批说明用于具体冲突及兼容边界查询。

## 文件用途

- 73节课程字段补丁.json：唯一统一导入源。
- 73节课程统一正文.md：阅读参考，不需要开发工具全文重读。
- 课程覆盖清单、合并覆盖清单：审计范围及编号。
- 执行记录汇总、复验报告：实际执行记录与日志。
- 分批原始资源：完整保留原分批正文、夹具、补丁、复验及限制说明，勿再次分批导入。

## 限制

新增示例本地 SQLite 验证通过，不代表 MySQL 原生、浏览器执行器或移动界面已经验证。保留企业主查询及原结果引用，未重新运行完整企业库。部分早期合并来源已有固定提交对照，后续主要依据现行映射整合，未逐篇审核所有旧版全文；不得把覆盖检查视作全文无遗漏证明。统一导入程序需在真实仓库预检，当前未对用户本地工程写入；不另行修改练习、闪卡、导航或远端仓库。索引和事务计划结果可能随数据库版本变化。第八批中的多语句、约束拒绝测试等仅在隔离环境运行，按该批说明展示。

统一导入程序已在模拟80节目录中执行预检及写入测试，确认第一批7节、保护字段及未指定检查点保留；不是实际项目集成测试。

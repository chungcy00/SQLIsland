## kp20-01 多表汇总与贡献率

### 核心概念

### SQL 示例

管理层想知道各门店贡献，比较范围是同期全部线下实体门店。

先左连接订单和门店保留主档，再聚合到门店粒度。SUM OVER 在所有门店行上给出相同总额，NULLIF 保护分母，最后根据销售额和编号排序。

**汇总各门店净销售并保留无销售门店**

```sql
WITH totals AS (
 SELECT s.store_id, COALESCE(SUM(o.net_cents),0) net_cents
 FROM stores s LEFT JOIN v_order_net o ON o.store_id=s.store_id
  AND o.channel='store' AND o.order_date BETWEEN '2025-01-01' AND '2025-12-31'
 GROUP BY s.store_id
)
SELECT * FROM totals ORDER BY 1, 2 LIMIT 3;
```

| store_id | net_cents |
| --- | --- |
| 1 | 450 |
| 2 | 80 |
| 3 | 0 |

```sql
WITH totals AS (
 SELECT s.store_id, COALESCE(SUM(o.net_cents),0) net_cents
 FROM stores s LEFT JOIN v_order_net o ON o.store_id=s.store_id
  AND o.channel='store' AND o.order_date BETWEEN '2025-01-01' AND '2025-12-31'
 GROUP BY s.store_id
)
SELECT store_id,net_cents,ROUND(100.0*net_cents/NULLIF(SUM(net_cents) OVER(),0),2) sales_pct
FROM totals ORDER BY net_cents DESC,store_id
```

### 执行结果

| store_id | net_cents | sales_pct |
| --- | --- | --- |
| 1 | 450 | 84.91 |
| 2 | 80 | 15.09 |
| 3 | 0 | 0.0 |

无销售门店仍显示销售额 0；总体也为 0 时贡献率为 NULL。若要看前三门店贡献，应先算总体再筛前三。

### 辨析与易错点

订单视图一行代表一笔有效订单。左连接保留无订单门店，先按门店聚合才得到可比较的门店净销售。SUM(net_cents) OVER()在全部门店汇总行上求和，每行仍保留门店粒度。窗口内不分区，避免每店贡献率都等于100%。线上订单不归入线下门店总体，不能混入分母。

示例采用可逐笔核对的小型数据，练习采用正式业务数据库。金额单位为马币分。

### SQL 示例

商品经理需要每家门店的前三件商品，要求并列时仍最多三件。

先按门店、商品合计净销售，再用 ROW_NUMBER 按门店分区，从高到低编号，以商品编号拆同额。外层应用前三名条件。把分区键改为部门、排序键改为薪资即可得到部门内名单；保留同薪名次时需改用适合并列规则的排名函数。

 WHERE channel='store' AND order_date BETWEEN '2025-01-01' AND '2025-12-31'
 GROUP BY store_id,product_id HAVING SUM(net_cents)>0
)
SELECT * FROM sales ORDER BY 1, 2, 3 LIMIT 3;

### 辨析与易错点

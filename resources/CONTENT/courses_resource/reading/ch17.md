## kp17-01 表结构与数据约束

### 核心概念

建表定义字段类型、主键、非空、唯一、检查约束及外键。约束在写入时保障有效性。

库存表需要新增标签可用 ALTER TABLE ADD COLUMN，既有行的值由默认值和可空性决定。DROP TABLE 会删除整张表及数据，迁移演练应放在副本里，先核对外键和备份。

子表的非空外键须存在于父表，避免库存明细指向不存在的商品。SKU 可用 UNIQUE 保护业务编号，行主键仍用 id。若字段可空，UNIQUE 的重复值规则与是否允许 NULL 要分别核对。

### 语法

```sql
CREATE TABLE t (id INT PRIMARY KEY, qty INT NOT NULL CHECK(qty>=0));
```

### 执行思路

1. 在隔离库建表
2. 写入两条库存
3. 查询验证

### SQL 示例

**保留记录并新增结构**

在演练库先创建表、写入记录，再新增带默认值的标签。查询能看到原记录仍在，并获得标签默认值。

```sql
CREATE TABLE sample_stock (id INTEGER PRIMARY KEY, sku VARCHAR(30) NOT NULL UNIQUE);
INSERT INTO sample_stock VALUES (1,'MASK-1');
ALTER TABLE sample_stock ADD COLUMN label VARCHAR(30) DEFAULT '未分类';
SELECT id, sku, label FROM sample_stock ORDER BY id;
```

| id | sku | label |
| --- | --- | --- |
| 1 | MASK-1 | 未分类 |

```sql
SELECT id,qty FROM demo_stock ORDER BY id;
```

### 执行结果

| id | qty |
| --- | --- |
| 1 | 10 |
| 2 | 20 |

读到两条初始库存。主键限制重复，CHECK 约束合法数量，外键可防孤立记录；多人操作用事务保持一致。

### 辨析与易错点

NOT NULL 不代表非负；CHECK 不替代 NOT NULL。

MySQL 与 SQLite 的类型、主键和约束行为不同；只验证本例子集。

## kp17-02 数据修改与事务

### 核心概念

INSERT 新增行，UPDATE 修改匹配行，DELETE 删除匹配行；写操作先确定 WHERE 匹配范围。

把库存扣减和发货记录放入同一事务。先写后查，全部正确时 COMMIT，任一步失败时 ROLLBACK。用同一连接查询事务后的库存，可以直接核对回滚有没有撤销修改。

### 语法

```sql
INSERT INTO t(cols) VALUES(vals); UPDATE t SET col=val WHERE p; DELETE FROM t WHERE p;
```

### 执行思路

1. 插入三行
2. 修改编号2库存为25
3. 删除编号3
4. 查询剩余行

### 示例数据

### SQL 示例

修改库存时先限定对象，再检查提交后的值。

INSERT 新建行，UPDATE 用主键 WHERE 定位，DELETE 删除指定记录。先用同条件 SELECT 核对范围，成组变更时用事务。START TRANSACTION 后先读回核对，正确时 COMMIT，发现差异时 ROLLBACK；MySQL 的部分 DDL 会隐式提交。

**写完后验证再决定是否提交**

临时将数量从 20 改成 15，回滚后再查同一编号，会重新看到 20。库存变动与发货记录应共享同一个事务。

```sql
CREATE TABLE sample_stock (id INTEGER PRIMARY KEY, qty INTEGER NOT NULL);
INSERT INTO sample_stock VALUES (1,20);
BEGIN TRANSACTION;
UPDATE sample_stock SET qty = qty - 5 WHERE id = 1;
ROLLBACK;
SELECT id, qty AS qty_after_rollback FROM sample_stock ORDER BY id;
```

| id | qty_after_rollback |
| --- | --- |
| 1 | 20 |

```sql
SELECT id,qty FROM demo_stock ORDER BY id;
```

### 执行结果

| id | qty |
| --- | --- |
| 1 | 10 |
| 2 | 25 |

示例更新后 ID 2 为 25。若预览发现目标范围意外扩大，应回滚并修正条件。

### 辨析与易错点

DELETE 删除行；DROP 删除表结构；UPDATE 无 WHERE 会修改全部行。

只在隔离副本运行，不改内置题库。

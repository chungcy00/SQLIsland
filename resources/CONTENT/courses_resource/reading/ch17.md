# 第17章 数据表管理

阶段：实战｜学习目标：理解建表、修改、约束与事务，不破坏内置模板。

## kp17-01 CREATE TABLE 与约束

### 核心概念

建表定义字段类型、主键、非空、唯一、检查约束及外键。约束在写入时保障有效性。

### 语法

```sql
CREATE TABLE t (id INT PRIMARY KEY, qty INT NOT NULL CHECK(qty>=0));
```

### 执行思路

1. 在隔离库建表
2. 写入两条库存
3. 查询验证

### 示例数据

### SQL 示例

建表时把必要数据规则写成约束，减少后续纠错。

先创建有主键与数量校验的表，再读回预置行验证。修改结构前先确认依赖，试验时使用个人库或临时副本。UNIQUE 可为备用键去重。ALTER TABLE 用于调整结构，DROP TABLE 会删除表及数据，执行前先检查引用和备份。

```sql
SELECT id,qty FROM demo_stock ORDER BY id;
```

### 执行结果

| id | qty |
| --- | --- |
| 1 | 10 |
| 2 | 20 |

读到两条初始库存。主键限制重复，CHECK 约束合法数量，外键可防孤立记录；多人操作用事务保持一致。

### 辨析与易错点

NOT NULL 不代表非负；CHECK 不替代 NOT NULL。

MySQL 与 SQLite 的类型、主键和约束行为不同；只验证本例子集。

关联题目：q0231

## kp17-02 INSERT、UPDATE、DELETE

### 核心概念

INSERT 新增行，UPDATE 修改匹配行，DELETE 删除匹配行；写操作先确定 WHERE 匹配范围。

### 语法

```sql
INSERT INTO t(cols) VALUES(vals); UPDATE t SET col=val WHERE p; DELETE FROM t WHERE p;
```

### 执行思路

1. 插入三行
2. 修改编号2库存为25
3. 删除编号3
4. 查询剩余行

### 示例数据

### SQL 示例

修改库存时先限定对象，再检查提交后的值。

INSERT 新建行，UPDATE 用主键 WHERE 定位，DELETE 删除指定记录。先用同条件 SELECT 核对范围，成组变更时用事务。START TRANSACTION 后先读回核对，正确时 COMMIT，发现差异时 ROLLBACK；MySQL 的部分 DDL 会隐式提交。

```sql
SELECT id,qty FROM demo_stock ORDER BY id;
```

### 执行结果

| id | qty |
| --- | --- |
| 1 | 10 |
| 2 | 25 |

示例更新后 ID 2 为 25。若预览发现目标范围意外扩大，应回滚并修正条件。

### 辨析与易错点

DELETE 删除行；DROP 删除表结构；UPDATE 无 WHERE 会修改全部行。

只在隔离副本运行，不改内置题库。

关联题目：q0232、q0235

关联闪卡：fc0129、fc0131、fc0133、fc0135

# 第06章 聚合函数

阶段：核心｜学习目标：计算计数、金额、平均值及极值。

## kp06-01 COUNT 的三个形式

### 核心概念

COUNT(*) 统计行；COUNT(col) 忽略该列 NULL；COUNT(DISTINCT col) 统计不同非空值。

### 语法

```sql
COUNT(*); COUNT(col); COUNT(DISTINCT col)
```

### 执行思路

1. 统计4行
2. 排除缺失得到3
3. 去重后得到2

### 示例数据

nullable_values

| id | value | note |
| --- | --- | --- |
| 1 | NULL | NULL |
| 2 | 0 |  |
| 3 | 10 | ok |
| 4 | 10 | ok |

### SQL 示例

同一列可分别回答录入行数、填报数和不同取值数。

COUNT(*) 数全部行，COUNT(value) 数非空值，COUNT(DISTINCT value) 在非空值中去重后再数。

```sql
SELECT COUNT(*) AS rows_count, COUNT(value) AS nonnull_count, COUNT(DISTINCT value) AS unique_count FROM nullable_values;
```

### 执行结果

| rows_count | nonnull_count | unique_count |
| --- | --- | --- |
| 4 | 3 | 2 |

四行记录有三个非空值和两个不同取值。可用这三个统计量解释填报率和样本的重复程度。

### 辨析与易错点

COUNT(0) 对常量非空逐行计数，不表示零值的数量。

空输入的 COUNT 返回0。

关联题目：q0061、q0065、q0069、q0070、q0074

关联闪卡：fc0036、fc0040、fc0042

## kp06-02 SUM 与 AVG

### 核心概念

SUM 汇总非空数值；AVG 的分母是非空数值个数，不是总行数。

### 语法

```sql
SUM(col); AVG(col)
```

### 执行思路

1. 忽略 NULL
2. 总和20
3. 除以3

### 示例数据

nullable_values

| id | value | note |
| --- | --- | --- |
| 1 | NULL | NULL |
| 2 | 0 |  |
| 3 | 10 | ok |
| 4 | 10 | ok |

### SQL 示例

在汇报均值前核对样本分母，避免把缺失记录默认为零。

SUM、AVG 忽略 NULL；均值相当于总和除以非空行数。若需要补零，要在聚合前明确写 COALESCE。

```sql
SELECT SUM(value) AS total, AVG(value) AS mean FROM nullable_values;
```

### 执行结果

| total | mean |
| --- | --- |
| 20 | 6.666666666666667 |

20 除以 3 得约 6.67，零参与计算，缺失不计。计算跨组均值时应合并各组的分子和分母。

### 辨析与易错点

AVG(COALESCE(value,0)) 会改变分母。

没有有效数值时 SUM/AVG 返回 NULL；数值精度按引擎处理。

关联题目：q0062、q0068、q0072、q0075

关联闪卡：fc0037、fc0039、fc0041、fc0043

## kp06-03 MIN 与 MAX

### 核心概念

MIN/MAX 返回非空值的最小及最大值，不自动返回对应整行。

### 语法

```sql
MIN(col); MAX(col)
```

### 执行思路

1. 读取全部价格
2. 比较极值

### 示例数据

products

| product_id | product_name | category | price | stock |
| --- | --- | --- | --- | --- |
| 1 | Mask | 护肤品 | 15 | 150 |
| 2 | Serum | 护肤品 | 89 | 40 |
| 3 | Cleanser | 护肤品 | 35 | 200 |
| 4 | Cream | 化妆品 | 65 | 180 |
| 5 | Sunscreen | 化妆品 | 45 | 80 |

### SQL 示例

获得价格范围用于检查跨度，再回原表寻找对应商品。

MIN 与 MAX 将非空价格压成一行，不保留对应商品编号。若需要商品明细，用子查询比较极值或使用排名。

```sql
SELECT MIN(price) AS min_price, MAX(price) AS max_price FROM products;
```

### 执行结果

| min_price | max_price |
| --- | --- |
| 15 | 89 |

区间是 15 到 89，最低价可能属于多件商品。把编号任意放进聚合输出不能证明它对应极值。

### 辨析与易错点

MAX(price) 不等于价格最高商品的所有字段。

需要全部并列最高行时使用子查询或排名。

关联题目：q0063、q0064、q0067

关联闪卡：fc0038

# 第09章 条件表达式

阶段：核心｜学习目标：分类、条件计数以及安全处理分母。

## kp09-01 CASE WHEN 分类

### 核心概念

按顺序检查 WHEN，返回首个为真的分支；ELSE 提供默认结果。

### 语法

```sql
CASE WHEN condition THEN value ELSE other END
```

### 执行思路

1. 先判零库存
2. 再判小于50
3. 其余归正常

### 示例数据

products

| product_id | product_name | category | price | stock |
| --- | --- | --- | --- | --- |
| 1 | Mask | 护肤品 | 15 | 150 |
| 2 | Serum | 护肤品 | 89 | 40 |
| 3 | Cleanser | 护肤品 | 35 | 200 |
| 4 | Cream | 化妆品 | 65 | 180 |
| 5 | Sunscreen | 化妆品 | 45 | 80 |

### SQL 示例

库存标签要求互斥分类，缺货优先于低库存。

CASE 按写下的顺序判断，首个真条件决定值。先判 stock=0，再判 stock<50，否则归正常。

```sql
SELECT product_id, CASE WHEN stock=0 THEN '缺货' WHEN stock<50 THEN '低库存' ELSE '正常' END AS stock_level FROM products ORDER BY product_id;
```

### 执行结果

| product_id | stock_level |
| --- | --- |
| 1 | 正常 |
| 2 | 低库存 |
| 3 | 正常 |
| 4 | 正常 |
| 5 | 正常 |
| 6 | 缺货 |

库存 40 为低库存，0 为缺货。若库存允许 NULL，增加缺失分支，避免默认归正常。

### 辨析与易错点

CASE 是表达式而非过滤语句。

省略 ELSE 时未匹配返回 NULL。

关联题目：q0120、q0123、q0125、q0128

关联闪卡：fc0062、fc0063、fc0068、fc0069

## kp09-02 IF 与条件聚合

### 核心概念

MySQL IF(condition,a,b) 可用于简单二选一；CASE 更通用。SUM(CASE...) 可在同一查询统计不同子集。

MySQL IF(条件,真值,假值) 适合二选一，条件为 NULL 时也落入假值分支。需要把“库存未知”单列时，应先在 CASE 中用 IS NULL 判断，避免把未知误归为正常。

### 语法

```sql
SUM(CASE WHEN p THEN 1 ELSE 0 END)
```

### 执行思路

1. 每行映射为0或1
2. 分别求和

### 示例数据

products

| product_id | product_name | category | price | stock |
| --- | --- | --- | --- | --- |
| 1 | Mask | 护肤品 | 15 | 150 |
| 2 | Serum | 护肤品 | 89 | 40 |
| 3 | Cleanser | 护肤品 | 35 | 200 |
| 4 | Cream | 化妆品 | 65 | 180 |
| 5 | Sunscreen | 化妆品 | 45 | 80 |

### SQL 示例

一趟扫描同时统计低库存和正常库存商品。

CASE 将每个条件转换成当前行的 1 或 0，SUM 按类别累计。可改用 COUNT(CASE WHEN 条件 THEN 1 END)，不满足时返回 NULL。MySQL 的 IF(条件,真值,假值) 适合生成单列二选一；需要多分支或跨库兼容时使用 CASE。

**把一条规则转成显示标签**

IF 的第三个参数处理假或未知条件。这个样例的库存来自非空商品记录，若允许未知库存，应改成可显式判断 NULL 的 CASE。

```sql
SELECT product_id, IF(stock < 50, '需关注', '正常') AS stock_label
FROM products ORDER BY product_id;
```

| product_id | stock_label |
| --- | --- |
| 1 | 正常 |
| 2 | 需关注 |
| 3 | 正常 |
| 4 | 正常 |
| 5 | 正常 |
| 6 | 需关注 |

```sql
SELECT SUM(CASE WHEN stock<50 THEN 1 ELSE 0 END) AS low_count, SUM(CASE WHEN stock>=50 THEN 1 ELSE 0 END) AS normal_count FROM products;
```

### 执行结果

| low_count | normal_count |
| --- | --- |
| 2 | 4 |

本例低库存 2，正常 4。分组后同样可以按门店生成多个状态计数，注意同一行可能符合非互斥条件。

### 辨析与易错点

COUNT(CASE WHEN p THEN 1 ELSE 0 END) 会计入所有行。

MySQL IF 可换写 CASE；NULL 条件走 ELSE。

关联题目：q0122、q0126、q0127、q0130

关联闪卡：fc0064、fc0065、fc0066

## kp09-03 NULLIF 与安全除法

### 核心概念

NULLIF(a,b) 相等时返回 NULL，否则返回 a；用来避免零作分母。

### 语法

```sql
numerator / NULLIF(denominator,0)
```

### 执行思路

1. 分母为0转NULL
2. 其他记录进行小数除法
3. 保留两位

### 示例数据

products

| product_id | product_name | category | price | stock |
| --- | --- | --- | --- | --- |
| 1 | Mask | 护肤品 | 15 | 150 |
| 2 | Serum | 护肤品 | 89 | 40 |
| 3 | Cleanser | 护肤品 | 35 | 200 |
| 4 | Cream | 化妆品 | 65 | 180 |
| 5 | Sunscreen | 化妆品 | 45 | 80 |

### SQL 示例

指标包含除法时，分母 0 表示无法定义，应留给业务解释。

NULLIF(stock,0) 将零分母转换为 NULL。先乘 1.0 以保留小数运算，再由 ROUND 处理展示精度。

```sql
SELECT product_id, ROUND(1.0*price/NULLIF(stock,0),2) AS ratio FROM products ORDER BY product_id;
```

### 执行结果

| product_id | ratio |
| --- | --- |
| 1 | 0.1 |
| 2 | 2.23 |
| 3 | 0.17 |
| 4 | 0.36 |
| 5 | 0.56 |
| 6 | NULL |

库存为零的商品结果是 NULL。规则可以复用于毛利率、转化率和环比。

### 辨析与易错点

IFNULL 把缺失变成默认值，NULLIF 把特定值变为缺失。

示例比率只演示语法，不是业务库存指标；SQLite 整数除法需提升类型。

关联题目：q0119、q0121

关联闪卡：fc0067

## q0235 · 对指定商品补货
题型：独立编写　难度：中等　知识点：kp17-02

在独立教学数据库上练习安全的结构与记录修改，不会变动内置企业数据库。

仅将编号2的库存增加5件，不重置原有库存，不修改其他表。

公开数据：
```sql
CREATE TABLE practice_stock(product_id INT NOT NULL PRIMARY KEY,qty INT NOT NULL CHECK(qty>=0)); INSERT INTO practice_stock VALUES(1,10),(2,20),(3,0); CREATE TABLE guard(id INT PRIMARY KEY); INSERT INTO guard VALUES(99);
```

提示：
1. 明确是数据行还是结构发生变化；保留不应修改的其他数据与约束。
2. 结合《INSERT、UPDATE、DELETE》：INSERT 新增行，UPDATE 修改匹配行，DELETE 删除匹配行；写操作先确定 WHERE 匹配范围。
3. 可以从以下语句骨架开始：
UPDATE practice_stock …;
